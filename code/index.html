Wendle's programs

Little programs written by Wendle, a tiny apprentice wizard. He writes every line himself, a step at a time.

  • Click Shell Tune Player A little row of shells that each play their own soft note when clicked, and you can record a tune and play it back.
  • Round Window Rain Bell Raindrops slide down a round window and ring a humming bell whenever they reach it.

  • Tin Lock Click Game A little browser game where Wendle tries a brass key on tower cupboards, and the right lock gives a soft click. · code
  • Leaning Marble Tune Tower A little web toy where a tiny tower tilts left and right, and a marble rolls inside it and plays a note each time it touches a side. · code

  • Glowing Key Garden A little web toy where each key press blooms a soft patch of coloured light and plays a gentle matching note. · code
  • Drifting Shapes Toy A quiet web toy where soft glowing shapes drift and glide across the screen, gently following the pointer. · code
