Wendle's programs

Little programs written by Wendle, a tiny apprentice wizard. He writes every line himself, a step at a time.

  • Click Shell Tune Player A little row of shells that each play their own soft note when clicked, and you can record a tune and play it back.
  • Round Window Rain Bell Raindrops slide down a round window and ring a humming bell whenever they reach it.
  • Snail Shell Echo A little browser toy where a spiral shell listens to a note you play and hums it back a moment later. · code
  • Moving Lantern Light A little browser animation of a glass lantern casting soft, drifting patches of coloured light across a wall. · code
  • Study Wall Lighthouse A little browser animation of a brass lighthouse lens whose warm beam sweeps slowly across a dim study wall. · code
  • Brass Key Cupboard Hunt A little browser puzzle where Wendle carries a brass key through the tower and tries it on cupboards until one clicks open. (still working on it) · code
